# Eigene Spielfigur

Lege hier ein animiertes Modell ab – das Spiel lädt es automatisch beim Start.
Ohne Dateien wird die eingebaute Platzhalter-Figur verwendet.

**Variante A – Mixamo (empfohlen):**
`character.fbx` (Figur, „With Skin“) + `idle.fbx`, `walk.fbx`, `run.fbx`, `jump.fbx`
(Animationen „Without Skin“, Option **In Place** aktivieren).

**Variante B – eine GLB-Datei:** `player.glb` mit Animationen, deren Namen
`idle`, `walk`, `run` und `jump` enthalten.

Details: siehe Abschnitt „Eigene 3D-Modelle“ in der Haupt-README.
